Introdução

O CSS, ou Cascading Style Sheets, nasceu da necessidade de separar o conteúdo de uma página web da sua apresentação visual. Antes dele, misturar estrutura e estilo deixava o código confuso e difícil de manter. Ao longo dos anos, o CSS evoluiu de uma linguagem simples de formatação pra um sistema poderoso, capaz de criar layouts responsivos, animações e experiências visuais complexas.

CSS1

O CSS1 foi a primeira recomendação oficial de folhas de estilo para a Web publicada pelo W3C. Sua criação resolveu uma das maiores crises de usabilidade e arqutetura da internet dos anos 90: a mistura de estrutura de conteúdo com apresentação visual.

1998

CSS2

O CSS2 foi publicado como recomendação oficial do W3C. O CSS2 foi a especificação que transformou a Web de um repositório de documentos estáticos em uma plataforma de design complexo, introduzindo conceitos fundamentais usados até hoje, como posicionamento absoluto e suporte a múltiplos mídias.
